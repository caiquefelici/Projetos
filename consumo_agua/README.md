# Consumo de Água

Eu criei este app com o objetivo de conscientizar o usuário sobre o consumo de água em diferentes tipos de imóvel, mostrando de forma prática e direta se o uso está dentro do esperado ou se há sinais de gasto excessivo.

## 💧 Ideia do projeto

A ideia central é permitir que o usuário informe:

- o tipo de imóvel;
- o consumo de água em metros cúbicos (m³);
- e, com base nessas informações, o sistema analisa o consumo e retorna uma mensagem sobre o nível de uso.

Com isso, o app funciona como uma ferramenta de educação ambiental e de autoconsciência, ajudando com feedback sobre o uso racional da água.

## 🏠 Como funciona

O usuário digita o tipo de imóvel, que pode ser:

- Comercial
- Casa
- Apartamento

Depois, informa o consumo de água em m³. A partir desses dados, o programa realiza a análise e apresenta uma resposta, como:

- consumo econômico;
- consumo moderado;
- consumo excessivo;
- ou mensagens específicas conforme o tipo de imóvel.

Essa lógica foi pensada para tornar a experiência simples, rápida e acessível, além de aproximar o projeto de uma aplicação útil no cotidiano.

## ⚙️ Tecnologias utilizadas

- Python
- Entrada de dados via terminal
- Condicionais para análise do consumo

## 🧠 Objetivo

O principal objetivo deste projeto é mostrar, de maneira objetiva, que o consumo de água pode ser monitorado e compreendido com poucos dados. Além disso, busca incentivar a reflexão sobre possível desperdício em caso de consumo excessivo ou parabenizar em casa de consumo baixo.

## ▶️ Como executar

1. Abra o terminal.
2. Acesse a pasta do projeto.
3. Execute o arquivo:

```bash
python app.py
```

4. Informe o tipo de imóvel e o consumo de água.
5. Veja a análise retornada pelo app.
