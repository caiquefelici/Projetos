# Sistema de Desconto em Compras

## Descrição

Programa desenvolvido em Python para calcular o desconto de uma compra com base no valor informado pelo usuário.

## Política de descontos

- Compras menores que R$ 200 recebem 5% de desconto.
- Compras entre R$ 200 e R$ 299,99 recebem 10% de desconto.
- Compras maiores ou iguais a R$ 300 recebem 15% de desconto.

## Funcionamento

O programa solicita o valor da compra e utiliza estruturas condicionais para escolher o desconto correspondente.

## Tecnologias utilizadas

- Python 3

## Como executar

1. Instale o Python 3.
2. Execute o arquivo:

```bash
python CaiqueFelici_Ag6_DS_I.py
